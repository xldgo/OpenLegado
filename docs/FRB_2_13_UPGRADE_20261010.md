# FRB 2.13.0 与 Dart 下限升级记录

任务状态以 [Active 计划](REFACTORING_ACTIVE_PLAN.md) 的 `FRB-UPGRADE-20261010` 为准。

## 范围与基线

- 用户于 2026-10-10 同意独立升级；基线为 `f9829708d`，分支为 `feature/rust-frb-2.13.0`。
- Flutter 保持 3.47.7，其自带 Dart 为 3.13.5；应用版本保持 `2.0.369+370`。
- Dart 下限由 3.8 提高至 3.13；FRB Dart runtime、Rust runtime 和 codegen 统一为 2.13.0。
- 原有阅读行为、业务接口、JSON、事件流、数据库及平台原生接线保持现状。
- 升级范围已先登记 [API 契约](API_CONTRACT.md)，生成物由固定版本 codegen 同次生成。

## Dart 生成链兼容处理

Dart 下限提高至 3.13 后，Freezed 2.5.8 生成的普通构造参数含 `final`，实际测试编译失败。
这对应上游已确认的 Dart 3.13 兼容问题，不能通过手改生成文件或放宽不可变约束解决。
采用当前最新稳定生成链：

| 依赖 | 升级前 | 升级后 |
|---|---|---|
| `freezed` | 2.5.8 | 4.0.2 |
| `freezed_annotation` | 2.4.4 | 3.1.0 |
| `build_runner` | 2.5.4 | 2.16.2 |
| `json_serializable` | 6.9.5 | 6.14.1 |
| `json_annotation` | 4.9.0 | 4.12.0 |
| `analyzer` | 7.3.0，直接固定 | 14.5.0，由生成器共同约束 |

按 Freezed 新版要求，30 份手写文件中的 64 个工厂模型/状态类声明改为 `abstract class`。
源码比对确认这些文件只有声明修饰符变化，构造参数、默认值、方法和 JSON 注解保持原样。
`build.yaml` 继续保留 `explicit_to_json: true`，另由 Freezed 自身执行格式化，避免模板行尾空格。

仓库没有使用 `@riverpod`、`@Riverpod` 或 `riverpod_annotation` 导入，分析配置也未启用
`custom_lint`；因此移除未使用的注解包、`riverpod_generator`、`riverpod_lint` 和
`custom_lint` 声明。旧生成器限定 analyzer 7，最新 custom_lint 仍限定 analyzer 8，均与
Freezed 4 的 analyzer 14 要求冲突。`flutter_riverpod` 运行库继续使用锁定的 2.6.1。
